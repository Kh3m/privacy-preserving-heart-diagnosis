# Fonts

| File | What it is | License |
|---|---|---|
| `CustomIcons.ttf` | Generated icon font | Ships with this repository |
| `Inter-{Light,Regular,SemiBold,Bold}.ttf` | The app's text font, [Inter](https://github.com/rsms/inter) 4.1 | SIL Open Font License 1.1, see `Inter-OFL.txt` |

Both families are registered in `pubspec.yaml`. Inter is the default font,
set with `fontFamily: 'Inter'` in the `ThemeData` in `lib/main.dart`.
